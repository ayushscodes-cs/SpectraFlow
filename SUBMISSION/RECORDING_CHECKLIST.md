# Video Recording & Final Submission QA Checklist

## Video Recording Checklist
- [ ] Clean desktop background with dark theme aligned with app aesthetic.
- [ ] Webcam preview positioned with good frontal lighting (avoid backlight).
- [ ] Audio input clean, crisp, and free from background keyboard click noise.
- [ ] Screen resolution set to 1920x1080 (16:9 standard).
- [ ] Verify both rose (PPG) and teal (respiratory) waveform lines render smoothly.
- [ ] Demonstrate affirmative consent gate interaction upfront.
- [ ] Demonstrate breath pause (Screen Apnea alert trigger).
- [ ] Demonstrate Web Audio generative bio-adaptive drone toggle.
- [ ] Demonstrate session completion and telemetry ledger popup.
- [ ] Export video in 1080p MP4 format under 2 minutes.

## Final Competition Submission Checklist
- [ ] Functional application verified on Windows x64.
- [ ] Presage SmartSpectra SDK (`@smartspectra/node-sdk` v3.5.0) natively integrated.
- [ ] Public GitHub repository initialized and pushed.
- [ ] `README.md` includes setup instructions, API key instructions, architecture diagram, and license.
- [ ] `.env` and node_modules excluded from git via `.gitignore`.
- [ ] `.env.example` provided for clean clones.
- [ ] Automated test suite runs cleanly (`npx vitest run`).
- [ ] DEV Community submission formatted with `#devchallenge` and `#presagechallenge`.
- [ ] Camera consent and data handling explicitly disclosed.
- [ ] Nominated under both target optional award categories.
